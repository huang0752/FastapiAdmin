# 食品物流八套登录品牌与双 Site 主题设计规格

## 1. 目标

为 4 个系统与 2 个 Site 建立 8 套可辨识、属于同一产品家族的登录品牌组合，并让 Site 主题从登录页延续到登录后的整个后台。

系统包括：

1. 食品物流统一中控（control）
2. 食品安全质量追溯系统（trace）
3. 农产品配送管理系统（agri）
4. 冷链物流配送车辆管理系统（logistic）

Site 包括：

1. 华夏电投（data360）
2. 中能电投（znceedi）

## 2. 品牌结构

采用“产品家族式”结构。四个系统各有独立几何母题；同一系统的两个 Site 版本保持基础轮廓一致，通过切角、连接方式、配色和微动效形成明显差异，不能只做机械换色。

| 系统 | 几何母题 | 华夏电投特征 | 中能电投特征 |
|---|---|---|---|
| control | 中心节点与四向连接 | 硬朗切角、电流节点 | 圆润连接、能量节点 |
| trace | 盾形链路与校验节点 | 冰青扫描线 | 翡翠校验脉冲 |
| agri | 叶片轮廓与配送路径 | 蓝青路径光点 | 绿青生长光点 |
| logistic | 车辆轮廓与雪花轨迹 | 冰蓝低温粒子 | 青绿温控轨迹 |

所有 Logo 均为纯图形，不包含文字。每个品牌组合提供：

- 透明背景主图 PNG，用于侧栏、登录页和用户头像；
- 小尺寸 favicon PNG，针对 16–32 像素可读性优化；
- SVG 动态标记，用于登录页；
- SVG 静态降级标记，用于减少动态、低性能环境与打印场景。

## 3. Site 色彩体系

### 3.1 华夏电投（data360）

- 主色：`#2563EB`
- 深色基底：`#07172E`
- 高光：`#38BDF8`
- 主题基础：现有 Ocean preset
- 氛围：电力蓝、深海蓝、细线电流、精密网格

### 3.2 中能电投（znceedi）

- 主色：`#078C72`
- 深色基底：`#052E2B`
- 高光：`#2DD4BF`
- 主题基础：现有 Forest preset，但增加青绿色 Site 专属 token
- 氛围：能源青绿、深翡翠、柔和轨迹、稀疏能量粒子

成功、警告、错误等业务语义色保持统一，不随 Site 品牌改变语义。

## 4. 主题解析与锁定

主题由标准 Host 解析出的 Site 决定：

- `*.data360.org.cn` 与本地默认 Host 使用 data360；
- `*.znceedi.org.cn` 使用 znceedi；
- 后端 Site 配置返回 `site_code` 后，以服务端结果校正首屏推断；
- 未知生产 Host 延续现有 fail-closed 安全边界，本地 `127.0.0.1`/`localhost` 默认 data360。

Site 主题从登录前首屏生效，并延续到后台的主色、侧栏、按钮、选中态与图表色板。隐藏调色板与主题 preset 入口，清除或忽略历史缓存中与当前 Site 不一致的主题 preset。保留亮色/暗色切换，但两种模式均只能使用当前 Site 的色板。

## 5. 登录页动效

选择 A“精密几何”的克制高级动效：

- 首次载入以约 600ms 完成 Logo 节点组装；
- 背景节点缓慢漂移，鼠标移动只产生轻微视差；
- 每 6–10 秒触发一次产品专属短动画；
- 动画不遮挡输入区，不持续旋转整枚 Logo，不使用高密度粒子；
- `prefers-reduced-motion: reduce` 时完全静止；
- 页面不可见时暂停循环；
- 移动端和低性能环境关闭视差、减少粒子数量。

## 6. 页面应用范围

8 套品牌组合应用于：

- 浏览器标签 favicon；
- 登录页左上角、登录标题区域和动态主视觉；
- 登录后侧栏与顶栏品牌图；
- 右上角用户菜单头像；
- 个人中心头像；
- 明暗模式下的 Site 专属主题。

产品装配不再允许租户历史 Logo、FastapiAdmin 默认 Logo 或用户头像覆盖这些权威品牌表面。通用 default Assembly 保留框架原行为。

## 7. 技术边界

- 中控与产品仓库共享同一份品牌 token 契约，但各自保留本地实现，避免运行时跨仓依赖；
- 动画采用 CSS/SVG，暂不引入 WebGL、Canvas 动画框架或新增运行时依赖；
- 不改变后端 Site/Host 数据模型；
- 不改变用户上传头像字段，只在食品物流产品装配中隐藏上传入口并用系统 Logo 展示；
- 不允许 Site 主题选择器重新出现；明暗模式按钮保留。

## 8. 验收口径

本轮明确不进行浏览器自动化或人工浏览器测试。验收证据由以下部分组成：

1. 8 个主 Logo、8 个 favicon 与 8 个动静态 SVG 的尺寸、透明度、文件命名和可解析性检查；
2. 单元测试覆盖 Host/Site、系统、Logo、色板、动效状态和未知 Host 回退；
3. 源码契约测试证明调色板入口隐藏、明暗切换保留、用户表面使用系统 Logo；
4. products 三个 Assembly 和 control 的 TypeScript 类型检查；
5. 四套前端构建及产物扫描，证明 favicon、Logo、主题 token 和动画资源进入正确产物；
6. ESLint、Prettier 与 `git diff --check`。

浏览器视觉验收作为后续独立事项，不计入本计划完成条件。
