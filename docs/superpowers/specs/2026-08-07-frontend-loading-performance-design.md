# 前端加载性能与静态资源可靠性优化设计

## 背景与目标

当前前端慢同时包含四条链路：线上 HTTP/2 静态资源流偶发长时间无响应、生产首屏强制加载大量重型依赖、开发态全量预构建 Element Plus 样式，以及首屏和登录阶段存在不必要的配置接口串行等待。

本次目标是在不改变业务页面、权限语义、租户隔离和产品装配行为的前提下：

- 先让仓库默认 Nginx 静态资源链路稳定，临时关闭 HTTP/2；
- 将编辑器、终端、图表、AI 助手和离线图标等能力从全局首屏移出；
- 缩减 Vite 开发态依赖预构建范围，保留首次访问懒加载页面时不反复整页刷新的能力；
- 解除公开配置和租户配置之间没有数据依赖的串行等待；
- 给带内容哈希的静态资源增加长期不可变缓存，同时让入口 HTML 保持可更新；
- 用自动化测试、类型检查和生产构建结果验证边界。

## 已确认方案与取舍

### 1. HTTP/2 可靠性优先

仓库 Nginx 的 HTTPS 监听暂时从 HTTP/2 回退为 HTTP/1.1。理由是同一客户端对同一资源的对照探测中，HTTP/1.1 能稳定返回，而 HTTP/2 多次出现 6 至 20 秒无响应。该修改是仓库可控的止损措施，不把根因武断归结为 Nginx；部署后仍需结合服务器日志、不同网络和不同客户端复测，再决定是否恢复 HTTP/2。

### 2. 首屏只保留基础框架

应用启动只同步注册 Pinia、Router、国际化、权限指令和首屏必需的基础能力。以下能力改为使用页面或组件时加载：

- ECharts 不再通过插件聚合入口产生模块副作用；
- CodeMirror 和 Web Terminal 不再全局安装；
- AI 助手由根组件异步加载，未登录或功能关闭时不下载其实现；
- Iconify 不再注册三套完整图标库，只收集源码实际使用图标并生成一个最小本地图标集合；
- Element Plus 继续兼容当前组件写法，但不再额外注册全部图标；组件和样式优先由现有自动导入解析器按需处理。

业务页面继续通过现有组件封装使用这些能力，不改变菜单、路由或接口契约。对确实依赖全局安装的 CodeMirror、Terminal 页面，改为在对应封装组件内部显式引用，而不是放回应用入口。

### 3. 开发态预构建只覆盖实际使用范围

Vite 不再扫描 Element Plus 安装目录并加入所有组件的两套样式入口。改为从项目源码中提取实际出现的 Element Plus 组件名称，映射到已安装组件目录并只预构建对应样式；无法映射的名称忽略并交给现有按需解析器处理。

扫描结果由独立纯函数生成并测试：输入源码文本和可用组件名集合，输出稳定、去重、排序后的依赖入口。这样既减少冷启动，又避免维护手工清单。

### 4. 配置初始化并发化

系统参数、Host 站点配置和认证租户配置互不依赖，可以并行请求。配置 Store 先并发取得响应，再按固定优先级合并：系统配置低于站点配置，站点配置低于租户配置。任一非关键站点或租户请求失败时沿用现有降级语义；系统参数响应无效时仍不把配置标记为成功加载。

路由守卫仍需在首次导航前取得产品装配摘要，因为它决定路由是否允许；本次不绕过该安全边界。线上当前缺失的装配和站点公开接口属于部署版本不一致，前端继续保留本地默认配置降级，但不会把 404 当作成功数据。

### 5. 静态资源缓存

Nginx 对带哈希的 `/web/js/`、`/web/css/`、`/web/img/` 和字体资源设置一年缓存并标记 `immutable`。`/web/index.html` 和 SPA 回退入口使用 `no-cache`，确保新版本入口可以及时更新。保留动态 gzip，同时配置优先使用构建生成的 `.gz` 文件，避免每次请求重复压缩大文件。

## 测试与验收

### 自动化验证

- Vite 依赖扫描测试：仅生成实际使用组件的样式入口，结果去重且稳定；
- 插件入口测试：禁止重新引入 ECharts、CodeMirror、Terminal 和完整 Iconify 集合；
- 配置 Store 测试：三类请求并发发起，合并优先级和失败降级保持一致；
- AI 助手测试：功能关闭或未登录时不实例化异步组件；
- Nginx 配置静态断言：HTTPS 不启用 HTTP/2，哈希资源长期缓存，HTML 不缓存；
- 运行前端目标 Vitest、`pnpm type-check` 和生产构建。

### 构建产物验收

重新构建后记录入口 HTML 的同步脚本、modulepreload 和样式数量，以及首屏引用资源的原始体积。验收重点是 CodeMirror、Terminal、WangEditor、XGPlayer、ECharts 等不再无条件出现在登录页首屏加载链中。具体体积以当前依赖版本的构建结果为准，不在设计阶段承诺未经构建验证的数值。

### 部署后验收边界

本地构建和配置检查不能证明公网 HTTP/2 问题已永久消失。部署后需验证：

1. 浏览器协商为 HTTP/1.1；
2. `/web/` 与入口静态资源多次请求无 6 秒以上无响应；
3. 首次访问与二次访问的网络瀑布符合 HTML 不缓存、哈希资源长期缓存的策略；
4. 登录、刷新动态路由、租户切换和主要重组件页面功能正常。

## 非目标

- 不修改当前并发进行的租户初始管理员凭据功能；
- 不改后端权限、菜单、租户和产品装配语义；
- 不在未取得多端与服务器日志证据前宣称 HTTP/2 服务端根因已经定位；
- 不升级 Vue、Vite、Element Plus 或其他主要依赖版本；
- 不部署、不推送远端。
