# 食品物流八套登录数据品牌海报重设计规格

## 1. 结论

废弃第一版“中央放大 Logo、环形动效、稀疏几何背景”的登录左屏。8 个入口的左侧全部重新设计；第一版 8 个 Logo 也全部重做，不能在旧图形上局部润色。

范围为 4 个系统 × 2 个 Site：

- 食品物流统一中控 control
- 食品安全质量追溯系统 trace
- 农产品配送管理系统 agri
- 冷链物流配送车辆管理系统 logistic
- 华夏电投 data360
- 中能电投 znceedi

## 2. 视觉原则

采用“抽象业务数据艺术”，不使用写实宣传图、3D 微缩场景或中央大徽章。每个左屏是一张完整的动态数据品牌海报，Logo 退居识别位，业务叙事成为视觉中心。

高级感来自信息层级、留白、材质、动线与节奏，不来自堆叠粒子、发光、渐变或悬浮卡片。

## 3. 五层数据品牌海报

1. 品牌层：小尺寸 Logo、系统名、Site 标识。
2. 主叙事层：占左屏约 45% 的系统专属抽象业务画面。
3. 状态层：2–3 个半透明状态模块，只表达链路能力，不伪造经营数据。
4. 空间层：网格、等高线、路径和柔和光域构成前中后景。
5. 文案层：系统专属主张、说明和三个关键词，删除通用框架宣传语。

## 4. 四类独立业务场景

### control

- 多系统拓扑与数据汇聚流
- 状态：系统连接正常、数据链路运行中、告警通道可用
- 动效：节点依次接入，跨系统路径低频高亮
- 主张：让每一条食品链路协同运转

### trace

- 批次时间轴、可信校验与扫码轨迹
- 状态：批次校验完成、链路节点 6/6、质量节点已核验
- 动效：校验脉冲沿批次链移动，扫码节点短暂展开
- 主张：每一批食品，都有可信路径

### agri

- 田块网格、订单波次、分拣流与配送路径
- 状态：订单波次进行中、线路已优化、签收链路可用
- 动效：田块轻微生长，配送路径沿节点推进
- 主张：从田间到餐桌，准时抵达

### logistic

- 车辆空间轨迹、温度带、仓门事件与异常边界
- 状态：温区稳定、轨迹同步、异常通道可用
- 动效：温度曲线低频呼吸，车辆路径缓慢推进
- 主张：温度不断链，运输全程可控

四个场景不得共用一张主画面再换标题。允许共享底层动画工具和排版规则，但业务 SVG、状态配置和动效时间线必须独立。

## 5. Site 语言

### data360

- 电力蓝、冰青、深海蓝
- 精密网格、硬朗切角、明确节点
- 亮色背景不是纯白，采用冷蓝纸面、局部光域与细微噪点
- 暗色采用深海蓝，不使用纯黑

### znceedi

- 能源青绿、深翡翠、清透青
- 柔和轨迹、圆润连接、有机等高线
- 亮色采用青灰纸面和柔和绿域
- 暗色采用深翡翠，不使用纯黑

同一系统两个 Site 共享业务母题，但构图细节、连接方式、切角与节奏不同，不能只换色。

## 6. Logo 重设计

- 8 个 Logo 全部重做。
- 取消圆形黑底、盾牌徽章、粗重描边、外圈和光环。
- 采用透明背景的线面几何符号，最多两个主色和一个高光色。
- 大尺寸版本保留精密节点；favicon 使用独立简化路径，不直接缩小主图。
- 两个 Site 版本共享产品骨架，但节点结构与切角不同。
- Logo 内无文字，动态只作用于内部节点与路径。

## 7. 动效

- 首次进入总时长约 1.2 秒：品牌、主叙事、状态、文案分层出现。
- 环境动态极慢、低频；关键业务路径每 8–12 秒高亮一次。
- 指标只做状态切换，不模拟虚假实时数据增长。
- `prefers-reduced-motion: reduce` 时完全静止。
- 页面隐藏时暂停；移动端和低性能模式关闭视差并减少装饰层。
- 禁止整枚 Logo 持续旋转、高密度粒子、强发光和无业务含义漂浮物。

## 8. 页面边界

- 左侧从顶部品牌区、中心主视觉、状态标签、底部文案到背景全部重构。
- 右侧登录表单结构保持稳定，只同步 Site 色板、按钮和焦点态。
- 隐藏主题 preset/调色板入口，保留亮暗切换。
- Site 主题由 Host/Site 锁定，不能切换成另一 Site。
- favicon、侧栏、顶栏、用户菜单与个人中心继续使用对应系统/Site Logo。

## 9. 技术结构

- `SiteBrandIdentity`：解析系统、Site、Logo、色板、文案和状态配置。
- `LoginBrandScene`：分派四个独立场景组件。
- `BrandMotionLayer`：处理进入动画、环境动态、视差、暂停与降级。
- 四个场景分别为 control、trace、agri、logistic 组件，不在一个巨大模板中用条件分支堆叠。
- 配置数据不散落在 Vue 模板中。
- 使用 SVG/CSS，不引入 WebGL、Canvas 动画框架或额外运行时依赖。

## 10. 验收边界

本次不做浏览器或 Playwright 测试。

- 8 套 Logo/favicons 可解析性与唯一性测试
- 8 套身份和场景配置完整性测试
- 四个系统主场景不可互换契约
- 两个 Site light/dark token 与主题锁定测试
- reduced-motion、页面隐藏暂停和移动端降级测试
- products 三 Assembly 与 control 的 TypeScript、Vitest、构建和产物扫描
- ESLint、Prettier、`git diff --check`

不以测试通过宣称视觉效果已完成人工浏览器验收；后续如需视觉验收，应单独授权。
