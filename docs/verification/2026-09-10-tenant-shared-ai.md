# 租户共享 AI 验收记录

工作树：`FastapiAdmin-unified-control`，分支：`codex/unified-control-framework`。

## 实现

- 共享配置位于 `/api/v1/system/ai-config`，不依赖租户是否安装聊天插件；不改变聊天插件的访问检查。
- 管理入口根据服务端能力显示，每次打开重新检查。普通成员不显示租户 AI 标签，管理 API 返回 403。
- 租户模型/激活项/功能绑定按租户保存；共享密钥加密，返回掩码。聊天兼容个人配置优先、租户默认、部署默认。
- 租户写入锁防止并发读改写丢失；配置取消 24 小时 TTL；保存失败不返回成功。被绑定的模型禁止直接删除。
- 固定消息连通性检测，供应商错误脱敏；业务服务显式用 `scope="tenant"`。

## 验收环境和证据

- 中控前端 3100、后端 8110；产品前端 3101、后端 8111。真实本地 PostgreSQL、Redis，两个实例各自独立数据。
- Chrome + Playwright，通过页面登录中控、进入产品，点击头像配置中心。
- 浏览器新增模型并启用成功；编辑时 API Key 输入框为空，留空保存后连接仍成功。
- 清除共享默认、重新激活成功。启用并保存共享功能绑定成功。
- OpenAI 兼容测试服务位于本机 18119，后端真实 HTTP 调用成功；测试服务返回 401 时，页面收到脱敏 400，响应不包含测试密钥。
- 中控租户未安装聊天插件时仍可打开租户 AI。中控列表不包含产品保存的模型，验证实例隔离。
- 普通成员浏览器无租户 AI 标签；直接请求列表、新增、删除、探测、更新绑定均 403。
- 使用真实 Redis 配置、另一个用户上下文执行共享结构化运行时，经真实 HTTP 获得并验证 Pydantic 结果。此项为服务层验收，不冒充普通成员业务页面生成验收。
- Redis 中共享模型/激活/绑定 TTL=-1，存储值没有明文测试密钥。
- 最终系统基础路由下再次完成新增、编辑留空保留密钥、HTTP 连接检测、共享绑定、实例隔离和成员管理拒绝。直接导入 Worker 运行时的回归测试通过。

本次使用本地协议测试服务，没有使用真实云模型厂商密钥，未验证云厂商计费、可用模型和生产部署。
