# 最小个人访问能力验收

有效登录、租户有效并具有产品访问资格的账号可进入 `/workspace/personal`。不依赖业务菜单角色，不通过给员工授予用户查询/管理权限实现。保留旧 `/auth/control/waiting` 路径别名，已有回调链接兼容。

基础能力：查看本人姓名、账号、所属租户、登录方式，刷新可用业务功能、退出登录。本地账号可通过当前用户接口修改自己的姓名；联邦身份不提供本地密码及身份修改入口，由中控维护。

## 2026-09-10 Chrome 实测

- 新建员工 browserbasestaff 并开通产品访问资格，未分配任何业务角色；第一次 SSO 直接进入个人工作区，展示本人资料和基础访问已开通。
- 基础员工直接请求产品用户列表、用户新增、租户列表接口均403。刷新可用功能仍停留个人工作区，没有进入业务菜单。
- 管理员撤销 browserfixstaffy 的本地角色：旧业务查询403，旧菜单卸载，回到个人工作区；个人资料仍可读取。
- 恢复本地角色后，原个人工作区点击刷新可用功能，不重新登录即可进入业务页面；仍无新增权限。最终恢复测试员工只读角色。
- 中控本地账号在个人工作区保存本人姓名，实际当前用户更新接口返回200/code0（使用原姓名进行保存）；没有修改其他用户。
- 用户管理把无业务菜单的状态显示为“仅基础访问”；后端 pending 继续表示业务授权状态，不放宽禁用、租户/套餐有效期或产品访问资格校验。
